# CursorRunner

CursorRunner - это приложение для macOS, которое создает эффект хаотичного движения курсора мыши. При запуске приложение захватывает скриншот экрана, отображает его в полноэкранном режиме и начинает перемещать курсор маленькими случайными шагами каждые 0.1 секунды, рисуя траекторию мягким синим цветом на изображении. Приложение выходит, когда пользователь двигает мышью.

## Особенности

- **Захват скриншота**: При запуске автоматически захватывает текущее изображение экрана.
- **Полноэкранный режим**: Отображает скриншот на весь экран.
- **Хаотичное движение**: Курсор перемещается случайными маленькими шагами (-10 до +10 пикселей по X и Y).
- **Рисование траектории**: Рисует путь курсора мягким синим цветом на скриншоте.
- **Выход по движению мыши**: Приложение завершается, как только пользователь двигает мышью.
- **Защита от отключения экрана**: Предотвращает автоматическое отключение экрана во время работы.

## Требования

- macOS (тестировано на Sonoma)
- Xcode или clang для сборки из исходников

## Установка

### Готовая сборка

1. Скачайте `run2.app` из релизов.
2. Запустите приложение двойным кликом.

### Сборка из исходников

1. Клонируйте репозиторий:
   ```
   git clone https://github.com/yourusername/CursorRunner.git
   cd CursorRunner
   ```

2. Соберите приложение:
   ```
   clang++ -framework ApplicationServices -framework AppKit -framework CoreFoundation -framework IOKit main2.mm -o main2
   ```

3. Создайте .app пакет (опционально):
   ```
   mkdir -p run2.app/Contents/MacOS
   cp main2 run2.app/Contents/MacOS/run
   chmod +x run2.app/Contents/MacOS/run
   # Создайте Info.plist и PkgInfo по необходимости
   codesign -s - run2.app
   ```

## Использование

1. Запустите `run2.app`.
2. Приложение захватит скриншот и начнет двигать курсор хаотично, рисуя траекторию.
3. Чтобы выйти, просто подвиньте мышь - приложение закроется.

## Предупреждение

Это приложение может быть использовано как шутка или для демонстрации. Убедитесь, что оно не мешает важной работе.
